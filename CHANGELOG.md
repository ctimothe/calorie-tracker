All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-02-02

### Added
- Initial release of NutriScan AI
- AI-powered food image analysis using Google Gemini
- Real-time calorie and macro calculation
- Interactive nutrition charts using Recharts
- Drag-and-drop image upload interface
- Responsive design for mobile and desktop
- Detailed nutritional breakdown for multiple food items
- Health insights and recommendations
- Professional documentation (README, CONTRIBUTING, LICENSE)

### Technical
- React 19.2 with TypeScript 5.8
- Vite 6.2 build system
- Tailwind CSS styling
- Modular component architecture
- Type-safe development environment
